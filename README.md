# 🍕 Pizza Sales Analysis (SQL Project)

## 📌 Project Overview:

This project analyzes pizza sales data using SQL to generate useful business insights.
It helps understand sales performance, customer preferences, and revenue trends.

---

## 🛠️ Tools Used

* SQL (MySQL)
* GitHub

---

##  Dataset:

The dataset includes:

* Orders (date & time)
* Order details (quantity)
* Pizzas (price & size)
* Pizza types (name & category)

---

##  Analysis Performed:

###  Basic:

* Total orders
* Total revenue
* Highest priced pizza
* Most common pizza size
* Top 5 pizzas

###  Intermediate:

* Category-wise quantity & revenue
* Orders by hour
* Average pizzas per day
* Top pizzas by revenue

### Advanced:

* Revenue percentage by pizza
* Cumulative revenue

---

##  Key Insights:

* Some pizza categories generate higher revenue
* Peak orders happen in evening hours
* Few top pizzas contribute major sales
* Sales show continuous growth over time

---

##  How to Use:

1. Import dataset into MySQL
2. Run SQL queries
3. Analyze results
